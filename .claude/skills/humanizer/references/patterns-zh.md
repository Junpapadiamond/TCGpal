## 内容模式

### <a id="1"></a>1. 夸大象征意义、遗产与更广泛趋势

**警惕词：** 标志着、见证了、是……的体现/证明/缩影、扮演着至关重要/关键的角色、凸显/彰显了其重要性、反映了更广泛的、象征着持久的、为……奠定基础、代表着一个转折点、不断演变的格局、留下不可磨灭的印记、深深植根于。

**为什么：** 模型爱给任意事实硬安一个"更宏大的意义"，凭空拔高。

> 前：加泰罗尼亚统计局于 1989 年正式成立，标志着西班牙区域统计演变史上的关键时刻，是分散行政职能、加强区域治理这一更广泛运动的一部分。
> 后：加泰罗尼亚统计局成立于 1989 年，独立于西班牙国家统计局收集和发布区域统计数据。

### <a id="2"></a>2. 堆砌知名度与媒体背书

**警惕词：** 被多家媒体独立报道、地方/全国性媒体、由知名专家撰写、拥有活跃的社交媒体账号、坐拥百万粉丝。

**为什么：** 反复强调"很有名"，列一堆来源却不给具体内容。

> 前：她的观点被《纽约时报》、BBC、《金融时报》广泛引用，社交媒体粉丝超过 50 万。
> 后：在 2024 年《纽约时报》的采访中，她认为 AI 监管应关注结果而非方法。

### <a id="3"></a>3. -ing / "……着"式空洞分析

**警惕词：** 句尾挂一串"凸显着……""确保着……""反映着……""推动着……""展示着……"。

**为什么：** 在句子末尾续一个分词短语，假装有深度，其实是同义反复。

> 前：寺庙的蓝绿金三色与当地自然景观相呼应，象征着德州的蓝帽花与墨西哥湾，反映了社区与土地的深厚联系。
> 后：寺庙用了蓝、绿、金三色。建筑师说这是为了呼应当地的蓝帽花和墨西哥湾海岸。

### <a id="4"></a>4. 宣传 / 广告腔

**警惕词：** 充满活力的、丰富的（比喻义）、深刻的、坐落于、位于……的中心、令人叹为观止、必打卡、迷人的、著名的、开创性的（比喻义）、自然之美。

**为什么：** 模型在"文化/景点/遗产"题材上尤其压不住，爱堆夸张形容词。

> 前：坐落在贡德尔地区令人叹为观止的腹地，Alamata Raya Kobo 是一座充满活力的城镇，拥有丰富的文化遗产与迷人的自然风光。
> 后：Alamata Raya Kobo 是埃塞俄比亚贡德尔地区的一座城镇，以每周集市和 18 世纪教堂闻名。

### <a id="5"></a>5. 模糊归因 / 含糊措辞

**警惕词：** 行业报告显示、有观察者指出、专家认为、一些批评者认为、多方消息称（却从不点名）。

**为什么：** 把观点甩给一个不存在的"权威"，不给具体出处。

> 前：因其独特性，浩来河引起了研究者和保护人士的关注，专家认为它在区域生态中发挥着至关重要的作用。
> 后：据中国科学院 2019 年的调查，浩来河支持多种特有鱼类。

### <a id="6"></a>6. 套路化的"挑战与未来展望"段

**警惕词：** 尽管面临诸多挑战、尽管存在这些挑战、挑战与机遇并存、展望未来。

**为什么：** 文章结尾硬塞一个公式化的"挑战/展望"段，内容全是正确的废话。

> 前：尽管工业繁荣，Korattur 仍面临交通拥堵、水资源短缺等城市通病。尽管如此，凭借其战略区位与持续努力，它必将继续蓬勃发展。
> 后：2015 年三个 IT 园区开业后，交通拥堵加剧。市政于 2022 年启动了雨水排水工程，应对反复发生的内涝。

## 语言与语法模式

### <a id="7"></a>7. 过度使用的"AI 高频词"

**高频词：** 此外、与……保持一致、至关重要、深入探讨、强调、持久的、增强、培养、获得、相互作用、复杂性、关键的、格局、彰显、宝贵的、充满活力的、赋能、抓手、闭环、颗粒度。

**为什么：** 这些词在 2023 年后的文本里密度暴增，还爱扎堆出现。

> 前：此外，索马里菜肴的一大显著特征是加入骆驼肉。意大利殖民影响的持久证明，是当地饮食格局中对意面的广泛采纳，彰显了这些菜肴如何融入传统。
> 后：索马里菜里还有骆驼肉，被当作美味。意大利殖民时期传入的意面至今常见，尤其在南部。

### <a id="8"></a>8. 回避"是"（系动词绕弯）

**警惕词：** 作为/充当/扮演着 [一个]、设有/拥有/提供 [一个]。

**为什么：** 把简单的"是/有"换成累赘结构，显得正式实则啰嗦。

> 前：Gallery 825 作为 LAAA 的当代艺术展览空间，设有四个独立空间，拥有超过 3000 平方英尺的面积。
> 后：Gallery 825 是 LAAA 的当代艺术展览空间，有四个房间，总面积约 3000 平方英尺。

### <a id="9"></a>9. 否定式排比

**警惕词：** "不仅仅是……更是……""这不是……而是……""与其说……不如说……"被滥用。

> 前：这不仅仅是节拍在人声下流动，更是攻击性与氛围的一部分。这不是一首歌，而是一种宣言。
> 后：沉重的节拍强化了攻击性的基调。

### <a id="10"></a>10. 三段式法则（凡事凑三点）

**为什么：** 模型爱把想法硬凑成三组，显得"全面"。真人没那么工整。

> 前：活动包括主题演讲、小组讨论和社交机会，与会者将收获创新、灵感与行业洞察。
> 后：活动有演讲和小组讨论，中间还留了非正式交流的时间。

### <a id="11"></a>11. 同义词循环（刻意换词）

**为什么：** 模型有"重复惩罚"，于是同一个东西换着花样叫，读着累。

> 前：主人公面临许多挑战。主角必须克服障碍。这位中心人物最终取得胜利。这位英雄回到家中。
> 后：主人公历经重重困难，最终取胜，回到家中。

### <a id="12"></a>12. 虚假范围（"从 X 到 Y"）

**为什么：** 用"从……到……"撑场面，但 X 和 Y 根本不在一个有意义的尺度上。

> 前：我们的宇宙之旅，将带你从大爆炸的奇点到宏伟的宇宙网，从恒星的生死到暗物质的神秘之舞。
> 后：这本书讲了大爆炸、恒星形成，以及目前关于暗物质的理论。

## 风格模式

### <a id="13"></a>13. 破折号滥用

**为什么：** 模型用破折号（——）比真人频繁得多，模仿"有力"的销售文案。多数能换成逗号或直接删。

> 前：这个叫法主要由官方机构推广——而不是民众自己。你不会把"荷兰，欧洲"当地址写——但这种误标还在继续——哪怕在正式文件里。
> 后：这个叫法主要由官方机构推广，而不是民众自己。你不会把"荷兰，欧洲"当地址写，但这种误标在正式文件里仍然存在。

### <a id="14"></a>14. 粗体滥用

**为什么：** 机械地给短语加粗强调，读者并不需要。

> 前：它融合了 **OKR（目标与关键结果）**、**KPI（关键绩效指标）**，以及 **商业模式画布（BMC）** 等工具。
> 后：它融合了 OKR、KPI，以及商业模式画布等工具。

### <a id="15"></a>15. 内联小标题 + 冒号竖列

**为什么：** 每条都"**加粗标题：** 然后重复一遍标题"，信息密度极低。

> 前：
> - **用户体验：** 用户体验通过新界面显著改善。
> - **性能：** 性能通过算法优化得到增强。
> - **安全性：** 安全性通过端到端加密得到加强。
>
> 后：新版改进了界面，用算法优化加快了加载，并加上了端到端加密。

### <a id="16"></a>16. 标题大小写

英文里 AI 爱把标题每个词首字母都大写（Title Case）。**中文标题一般没有大小写问题，此条多数不适用**，仅在中英混排标题里留意。

### <a id="17"></a>17. emoji 装饰标题 / 要点

**为什么：** 在标题或要点前挂 🚀💡✅，正式中文写作里显得轻浮。私聊（chat 场景）里可酌情保留。

> 前：
> 🚀 **启动阶段：** 产品在 Q3 发布
> 💡 **关键洞察：** 用户更偏好简单
> ✅ **下一步：** 安排后续会议
>
> 后：产品在 Q3 发布。用户调研显示更偏好简单。下一步：安排后续会议。

### <a id="18"></a>18. 弯引号 / 引号混用

英文里 ChatGPT 爱用弯引号（“ ”）。中文里表现为该用中文引号（"" 或 「」）时混进了英文直引号，或全角半角混用。统一成一种即可。

## 交流痕迹

### <a id="19"></a>19. 对话残留（把聊天当正文）

**警惕词：** 希望这对您有帮助、当然可以！、没问题！、您说得太对了！、如果您需要我展开任何部分，请告诉我、这是一份……。

**为什么：** 把和聊天机器人的对话原封不动粘成了内容。

> 前：以下是法国大革命的概述。希望对您有帮助！如果想让我展开某部分，请告诉我。
> 后：法国大革命始于 1789 年，财政危机与粮食短缺引发了大范围动荡。

### <a id="20"></a>20. 知识截止 / 信息免责声明

**警惕词：** 截至 [日期]、根据我最后的训练数据、虽然现有资料有限、基于已有信息……。

> 前：虽然关于该公司成立的具体细节在现有资料中记录不多，但它似乎成立于 1990 年代某个时候。
> 后：据工商登记，该公司成立于 1994 年。

### <a id="21"></a>21. 谄媚 / 卑躬屈膝的语气

**为什么：** 过度讨好、反复夸对方问得好。

> 前：好问题！您说得完全正确，这确实是个复杂的话题。关于经济因素，您这点提得非常好。
> 后：你提到的经济因素，在这里确实相关。

## 填充与回避

### <a id="22"></a>22. 填充短语

直接替换：

- "为了达成这一目标" → "为此"
- "由于下雨这一事实" → "因为下雨"
- "在当前这个时间节点" → "现在"
- "在您需要帮助的情况下" → "如果需要帮助"
- "该系统具备处理……的能力" → "该系统能处理……"
- "值得注意的是，数据显示" → "数据显示"

### <a id="23"></a>23. 过度限定（一句话套好几层不确定）

> 前：这或许在某种程度上可能可以被认为，该政策也许会对结果产生某些影响。
> 后：该政策可能影响结果。

### <a id="24"></a>24. 通用积极结尾（正确的废话）

**为什么：** 用一段模糊的乐观收尾，什么信息都没有。

> 前：公司的未来一片光明，激动人心的时代即将到来，他们将继续追求卓越。这无疑是迈向正确方向的重要一步。
> 后：公司计划明年再开两家门店。

## 一个完整示例

> **改写前（满是 AI 味）：** 这次软件更新，是公司致力于创新的有力证明。此外，它带来了无缝、直观且强大的用户体验——确保用户能够高效达成目标。这不仅仅是一次更新，更是我们对生产力理解方式的一场革命。业内专家认为，它将对整个行业产生持久影响，彰显了公司在不断演变的技术格局中的关键作用。

> **改写后（人话）：** 这次更新加了批量处理、键盘快捷键和离线模式。参与内测的用户反馈不错，多数人说任务完成得更快了。

改了什么：删掉"是……的有力证明"（夸大象征）、"此外"（AI 高频词）、"无缝、直观且强大"（三段式 + 宣传腔）、破折号和"确保……"（空洞分析）、"不仅仅是……更是……"（否定排比）、"业内专家认为"（模糊归因）、"关键作用 + 不断演变的格局"（AI 高频词）；换成了具体功能和具体反馈。
