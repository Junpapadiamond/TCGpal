# TCGpal — strategy one-pager

## What TCGpal is
A cautious, honest "buy-before check" for TCG buyers. Counter-positioned against the hype/price-prediction category: it does NOT predict prices, hype cards, or decide for you. It helps you pause and check evidence (version, budget, market, condition) before an impulse purchase.

## Strengths (keep these)
- **Counter-positioning** — decision-quality tool in a category full of hype tools.
- **Philosophy enforced in code** — deterministic budget hard-stop overrides AI; honest "unavailable" for comps; graceful fallback. Values match implementation.
- **Right use of AI** — fills evidence gaps, not a chatbot, not price prediction.
- **Deterministic-first architecture** — pure, testable TS logic; AI is a thin explanation layer. Reusable across web/mobile/native.

## The #1 risk (unvalidated)
The core behavioral bet: **will someone in the grip of FOMO actually stop and open a check tool?** Impulse buyers hate friction. This assumption has zero real-user evidence yet. Everything is built from the founder's model of the problem, not from observed users. Validate this before building more.

## Sharpen these (currently fuzzy)
- **ICP** — collectors vs flippers have opposite needs (grail emotion vs margin/EV). Pick one primary user; let it cut features.
- **Wedge (acquisition)** — strongest is "paste a listing link → instant check" (rides existing behavior). Journal/budget = retention, not acquisition.
- **Aha moment** — make it concrete and screenshot-worthy: "asking price is X% above recent sold" or "this cert is fake / wrong version." Build toward a demonstrable single save.
- **Moat** — the journal/behavioral memory loop is the long-term defensible asset. Currently underused; prioritize it.
- **Success metric** — define a north star tied to real value (e.g., regretted-purchase rate, money saved, % of pauses the user later endorses).

## Distribution (this is the next move)
Early distribution = learning + seeding, not growth. And it's the SAME action as validating demand.

1. **Do things that don't scale.** Personally enter 3–5 communities where "should I buy this?" is already asked (Reddit r/PokemonTCG, r/PokeInvesting, r/pkmntcgtrades; trading/grading Discords; CN: 小红书, 集换社 微信群, 闲鱼). Find the question, run TCGpal, give the answer. Validates demand + seeds users + teaches you the real context.
2. **Build the loop into the product.** Make the Buy check verdict a clean, branded, shareable image with a back-link. The output is the ad. People already post "is this a good deal?" — your card is the answer others see.
3. **Win one channel first.** Buy-decision conversations happen live in Discord + Reddit (CN: 小红书 + 集换社 groups). Own one beachhead before spreading.
4. **Value-first, always.** TCG communities ban self-promotion. Lead with genuinely helpful answers; the tool is mentioned in passing. This matches the product's honest brand — same posture, product and founder.
5. **Wedge + aha + shareable artifact = a free distribution machine.** Prioritize the features that produce shareable saves (eBay sold compare, PSA cert check).

## Next 2 weeks (suggested)
1. Talk to / watch 5–10 real buyers; test the friction assumption with a card they're tempted by.
2. Lock one ICP + one wedge + one aha.
3. Ship the shareable verdict card + eBay sold deep link.
4. Run the "answer the question in communities" play in ONE channel; measure if people want it.
5. Instrument decisions + outcomes locally so you can later answer: does TCGpal change what people buy?

## One-line takeaway
You've proven you can build a coherent, tasteful, well-engineered 0→1 product. "Built well" ≠ "wanted." The next level isn't in the code — it's in users and distribution, and the first move serves both at once.
