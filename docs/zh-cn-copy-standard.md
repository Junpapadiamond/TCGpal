# TCGlens 简体中文文案规范

面向大陆简体中文卡牌玩家。写给正在收卡的人：他关心是不是同一版、品相怎么样、算上运费多少钱、卖家的评价如何。

## 写法

- 先说用户眼前的事。按钮用「开始比价」「就这张」「再查一张」；不要让用户学习内部术语。
- 用「你」，句子能直接说就直接说。口语不等于插科打诨，也不需要每句都带「卡友」「老哥」。
- 用具体信息代替抽象评价：照片几张、运费是否写清、哪里与所选版本对不上。
- 好读的句子保留。不要用禁词表机械替换，也不要为了制造节奏硬拆句子。
- 没查到、没确认、没写明是三种不同状态。不得改成「没有这张卡」「已经卖完」「卖家不靠谱」。
- 玩家昵称可以作为语气参考；卡名、卡号、版本标记、语言和系列名称必须保留可核对的目录信息。未验证中文搜索能力前，示例保留可用的英文卡名。

## 术语和边界

| 场景 | 用词 | 说明 |
|---|---|---|
| 买入单卡 | 收卡、想收哪张 | 不是开包、拆盒 |
| 单张未评级卡 | 裸卡 | 不暗示未经使用或没有瑕疵 |
| condition | 品相 | 商品品相始终写「卖家标注」 |
| NM / LP / MP / HP / DMG | 近全新（NM）/ 微瑕（LP）/ 明显瑕疵（MP）/ 重度瑕疵（HP）/ 损卡 | 中文是本产品的简明说明，不声称等同于国内平台品相档位，更不保证 NM 等于无瑕或评级 10 分 |
| 瑕疵 | 白点、白边、划痕、压痕、折痕、卡角磕碰 | 只有卖家写明才作为商品事实；示例要说「比如」 |
| 身份 | 卡名、卡号、系列、版本、卡图、稀有度 | 卡号不固定在所有游戏的左下角；同卡号也可能有不同异画、再版、工艺 |
| 图案变体 | 异画、平行版本 | 依据实际目录，不能把所有平行版本认作某一种异画 |
| 版本语言 | 英文版、日文版、简中 | 中文界面不代表搜索的是简中卡 |
| 商品 | 这条商品、这张卡、商品链接 | 比价条目用「条」，实体卡用「张」；不强行把每处商品都换成卡 |
| asking price | 标价、卡价 | 卖家要价，不等于已成交价 |
| pre-tax total | 税前总价 | 卡价 + 运费 + 必要买家手续费；未知费用不能当 0 |
| estimated total with tax | 预估到手价 | 只有含估算税且必要费用齐全时用，实际金额看结账页 |
| reference | TCGplayer 参考价 / NM 参考价 | 不把它说成某条商品或国内「集换价」；非 NM 对比不计入价格评分 |
| evidence | 商品信息、图文信息、照片和品相说明 | 来源审计中可以保留「证据」；主界面说清具体是什么 |
| seller record | 卖家评价、评价记录、好评率 | 没查到记录就是信息不足 |
| lens | 推荐方式；提示「你更看重」 | 综合推荐 / 总价最低 / 稳妥优先 / 图文最全 |
| receipt | 比价记录 | 分享记录、复制结果；不是交易凭证或鉴定证书 |
| source failure | 这次没查到数据 / 查询失败 | 已暂停与故障分别说明，暂停不暗示重试能修复 |
| Mercari | Mercari 美国站 | 当前适配器查美国站；不直接用日站昵称「煤炉」替代 |

「图文最全」比较照片数量与卖家描述是否完整，不能理解成已经看图验卡。「稳妥优先」按卖家记录和商品资料打分，不保证交易安全。

## 格式

- 中文句子用中文标点，中英文和数字之间留空格。金额沿用美元 `$`，不换算成人民币。
- 卡号、URL、枚举、字典 key、来源标题和商品原文不做机械翻译。
- 标签够短即可，不强求两字。保留「税前」「预估」「卖家标注」等必要限定。
- 说明就近写。错误提示告诉用户下一步能做什么，不推测故障原因。

## 维护与验证

范围包括 `i18n.tsx`、`verdict-copy.ts`、跨平台价格区、`ReceiptPageClient.tsx`、`MethodPageClient.tsx` 和中文问答提示。英文和数据契约保持原样。

1. 对照实际出现的页面改写，保留金额、条件、归因和缺失信息。
2. 更新已有界面测试中的文字断言；纯文案不用新增逐字复刻实现的测试。
3. 检查中英文桌面页及中文手机页，确认长文案、按钮和标题没有遮挡或横向溢出。
4. 运行仓库要求的发布检查。文案未改符号、导入或关系时不重新生成 Graphify。
